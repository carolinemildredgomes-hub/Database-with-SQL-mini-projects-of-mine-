# Hospital Analytics System

## Project Overview

The Hospital Analytics System is a SQL-based database project designed to simulate how healthcare organizations manage patient admissions and generate operational reports.

The project focuses on transforming raw hospital data into meaningful insights through SQL queries, views, joins, and aggregations.

## Problem Statement

Hospital administrators need answers to important questions:

* How many patients come from rural areas?
* Which departments receive the most admissions?
* What is the gender distribution of patients?
* Which departments are the busiest?

This project builds a relational database and analytical views to answer those questions.

## Database Schema

### departments

Stores hospital department information.

### patients

Stores patient demographic information.

### admissions

Stores patient admission records.

## Views Created

### rural_patients

Returns patients whose district contains the word "Rural".

### department_summary

Shows admission totals by department.

### busiest_departments

Ranks departments by admission volume.

### patient_statistics

Provides patient counts and gender distribution.
