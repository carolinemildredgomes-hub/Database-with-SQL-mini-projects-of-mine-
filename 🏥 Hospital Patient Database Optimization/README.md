# 🏥 Hospital Patient Database Optimization

## Overview

This project simulates a hospital management system and focuses on SQL query optimization using indexes. The database stores information about patients, doctors, appointments, prescriptions, and departments.

The objective is to analyze common healthcare-related queries and design efficient indexes that improve performance while minimizing storage overhead.

## Features

* Patient appointment history
* Doctor performance analysis
* Prescription lookup
* Department-based doctor search
* Query execution plan analysis
